The three settings

Smoothness 0.30

Controls how it arrives, not how far it goes. Each frame the view closes this fraction of whatever distance is left — so it starts fast and settles softly. Low glides for a long time; high snaps into place. This is the one that changes the feel.

Lines per notch 6

Controls how far one click of the wheel travels, counted in lines. Windows' own default is 3, so leaving it there means SuperScroll changes the feel without changing the distance you're used to.

Line height 136 px

What a “line” is worth in pixels. Playnite's rows are far taller than a line of text, so this is the conversion. Raise it if a notch feels short in grid view; lower it for dense list views. Together with the setting above it decides the distance per notch.

Playnite — whole row, immediately SuperScroll — eased

Why two panes and not one. Playnite scrolls in whole rows: its scroll position counts items, so the smallest move it can make is one entire row and nothing exists in between. SuperScroll switches the same list to counting pixels, which is what gives the animation something to move through.

Try the fast flick. On the left, five quick notches are five separate jumps. On the right each notch extends a journey already running, so it accelerates — that is the difference you feel most when scrolling a long library.
